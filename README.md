# 📍 Local Guide - Don't Ask, Just Go

A curated collection of favorite local spots in Cyprus, filtered by city and category. No tourist traps, just the places a "Certified Local" would actually go.

Built with **React**, **TypeScript**, and **Chakra UI**.

## ✨ Features

- 🏙️ **City Filtering**: Explore spots in Ammochostos, Paphos, Larnaca, Limassol, Nicosia, and Kyrenia.
- 📂 **Categories**: Filter by Food, Sea, Landmarks, or see everything at once.
- 🗺️ **Direct Navigation**: One-click access to Google Maps for every location.
- 📱 **Fully Responsive**: Optimized for mobile and desktop "on-the-go" usage.
- 🍺 **Support the Guide**: Integrated support links (PayPal, Revolut, BuyMeACoffee).

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) (Vite)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI Library**: [Chakra UI](https://chakra-ui.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/) (Phosphor, FontAwesome, Simple Icons)
